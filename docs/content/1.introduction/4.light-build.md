# Light build

`vue3-lottie` ships two entry points. They expose the same component, props, events and methods. The only difference is which `lottie-web` player they load.

| Import              | Player | Renderers               | Expressions | Uses `eval` |
| ------------------- | ------ | ----------------------- | ----------- | ----------- |
| `vue3-lottie`       | full   | `svg`, `canvas`, `html` | Yes         | Yes         |
| `vue3-lottie/light` | light  | `svg`                   | No          | No          |

## Why use the light build?

The full `lottie-web` player evaluates [After Effects expressions](https://helpx.adobe.com/after-effects/using/expression-basics.html) with `eval`. Bundlers such as Vite and Rollup flag this during the build:

```bash
Use of eval in "node_modules/lottie-web/build/player/lottie.js" is strongly discouraged as it poses security risks and may cause issues with minification.
```

If your animations don't rely on expressions, the light build removes this warning. It also produces a smaller bundle (roughly 200 KB less before compression). It also works with a strict Content Security Policy that doesn't allow `unsafe-eval`.

## Usage

Change the import path from `vue3-lottie` to `vue3-lottie/light`. Nothing else changes.

### Vue 3

```js
// main.js
import { createApp } from 'vue'
import Vue3Lottie from 'vue3-lottie/light'

createApp(App).use(Vue3Lottie).mount('#app')
```

Or import the component locally:

```vue
<script setup>
import { Vue3Lottie } from 'vue3-lottie/light'
</script>
```

### Nuxt 3

```ts
// plugins/Vue3Lottie.client.ts
import { Vue3Lottie } from 'vue3-lottie/light'

export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.vueApp.component('Vue3Lottie', Vue3Lottie)
})
```

## Limitations

::alert{type="warning"}
Only use the light build if your animations don't need the features below.
::

- **SVG renderer only.** Setting `renderer` to `canvas` or `html` logs a warning, and the animation will not render correctly.
- **No expressions.** Animations still play, but any property driven by an After Effects expression won't animate as designed. If an animation looks wrong with the light build, switch back to `vue3-lottie`.

::alert{type="info"}
Previously the workaround was a bundler alias that pointed `lottie-web` at `lottie_light.js`. You can remove that alias and import from `vue3-lottie/light` instead.
::
